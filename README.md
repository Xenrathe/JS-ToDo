# README

## Productivity Master 9000, an 80s/90s neon-themed productivity / to-do list app

![Screenshot of dogs being placed](https://github.com/Xenrathe/JS-ToDo/blob/main/PMaster.png?raw=true)

Productivity Master 9000 is a to-do list app that allows users to create projects with a due date and fill it with individual to-do items that can be checked, removed, and re-prioritized. Increase your productivity to 9000 - and beyond!

Productivity Master 9000 is active on GitHub pages: (https://xenrathe.github.io/JS-ToDo/)

### Features:

- Fully responsive layout for mobile, tablet, and desktop
- Uses Web Storage API (localStorage) to persist project/to-do list on a given device
- Saving / loading project/to-do list is automatic and unobtrusive
- Module / Class design keeps code organized and readable
- Intuitive drag/drop for shifting projects and to-do list priority

### Tech Stack:

- CSS: Vanilla
- JS: Bundled via Webpack, including various plugins
- Backend: N/A - no backend
- Other: Web Storage API (localStorage) for persisting data on single device
